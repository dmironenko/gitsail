# Поля конфигурации приложения

Приложение находится в `apps/<namespace>/<name>`. Обязательный файл `vars/base.yaml` может содержать три блока верхнего уровня в указанном порядке: `build`, `app`, `compose`.

| Поле | Назначение |
|---|---|
| `build.repository` | Репозиторий исходников, который клонирует Dockerfile приложения. |
| `build.tag` | Git-тег, ветка или commit, выбранный Dockerfile. |
| `app` | Настройки приложения и секреты в исходной структуре приложения; доступны шаблонам через `.Vars.app`. |
| `app.env` | Необязательная карта переменных окружения. Отрендерьте её в файл и укажите его в Compose `env_file`; автоматически значения не передаются. |
| `compose` | Конфигурация проекта и сервисов Docker Compose. См. официальную [Compose Specification](https://compose-spec.github.io/compose-spec/). |
| `compose.x-gitsail.enabled` | Расширение GitSail: `false` отключает приложение, любое другое состояние включает его. Удаляется перед проверкой Compose. |

Дополнительные ключи внутри `build` и `app` определяются приложением. Поля внутри `compose` определяются Compose Specification, где приведён их полный список. Для проверки репозитория запустите `gitsail validate`. Если настройки сервиса не заданы явно, GitSail добавляет значения restart, общей сети и ротации логов.

В `prod` читается только `base.yaml`; в остальных окружениях сначала читается `base.yaml`, затем `stage.yaml`. Словари объединяются рекурсивно, списки и значения заменяются, `null` удаляет унаследованные ключи.
