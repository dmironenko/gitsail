# Поля конфигурации хоста

Конфигурацию хоста передают через `--config`; по умолчанию используется `gitsail.yaml` в текущем каталоге. Относительные пути отсчитываются от файла конфигурации.

| Поле | Назначение |
|---|---|
| `version` | Обязательная версия схемы: `1`. |
| `installation` | Обязательное имя установки, совместимое с Docker; изолирует эту установку GitSail. |
| `source.mode` | Режим источника: `local` или `remote`. |
| `source.path` | Путь к локальному Git-репозиторию; обязателен в режиме `local`. |
| `source.url` | URL удалённого Git-репозитория; обязателен в режиме `remote`. |
| `source.branches` | Обязательное соответствие имён окружений и веток. Особое имя окружения — только `prod`. |
| `source.poll_interval` | Частота проверки изменений; по умолчанию `1m`. |
| `source.auth.type` | `https`, `ssh` или отсутствует/`none`. Применяется только к удалённому источнику Git. |
| `source.auth.token_file` | Файл токена для HTTPS. |
| `source.auth.key_file` | Файл закрытого SSH-ключа. |
| `source.auth.known_hosts_file` | Файл известных SSH-хостов. |
| `state_dir` | Обязательный закрытый каталог состояния. В режиме `local` должен быть вне репозитория. |
| `age_key_file` | Необязательный age-ключ для расшифровки значений `ENC[...]`; храните вне Git. |
| `docker.host` / `docker.context` | Необязательный адрес Docker или контекст; укажите не более одного. |
| `reconcile.parallelism` | Число одновременно обновляемых приложений; по умолчанию `4`. |
| `reconcile.git_timeout` | Таймаут операций Git; по умолчанию `30s`. |
| `reconcile.deploy_timeout` | Таймаут развёртывания; по умолчанию `5m`. |

Для длительности используется формат Go, например `2s`, `1m`, `5m`. См. рецепт [установки GitSail](../recipes/install.md).
