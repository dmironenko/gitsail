# Шаблоны и доступные поля

Шаблоны конфигурации приложений используют синтаксис Go templates. Файл с окончанием `.tmpl` обрабатывается и сохраняется без этого суффикса; остальные файлы копируются как есть. В шаблоне доступны:

| Поле | Значение |
|---|---|
| `.Vars` | Объединённые vars приложения, в том числе `.Vars.build`, `.Vars.app`, `.Vars.compose`. |
| `.Installation` | Имя установки. |
| `.Env` | Имя текущего окружения. |
| `.Environments` | Список настроенных окружений. |
| `.Namespace` | Namespace приложения. |
| `.App` | Имя приложения. |
| `.Runtime.ProjectName` | Сгенерированное имя Compose-проекта. |
| `.Runtime.NetworkName` | Имя сети установки. |
| `.Runtime.Image` | Сгенерированное имя образа при сборке. |

Доступны функции `toYAML`, `toJSON`, `quote`, `quoteEnv`, `indent`, `get`, `default`, `dict`, `list`, `merge`, `network`. Функция `network` планирует создание сети, управляемой установкой. Интерполяция Compose отключена, поэтому символ `$` в значениях сохраняется.

Встроенный шаблон Compose можно экспортировать командой `gitsail template export compose --output compose.yaml.tmpl`. Пользовательский шаблон заменяет встроенный и должен сохранять обязательные runtime-поля. См. рецепт [переменных окружения](../recipes/environment-variables.md).
