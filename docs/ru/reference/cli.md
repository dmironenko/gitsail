# Команды CLI

Для указания конфигурации любая команда принимает `--config PATH`; по умолчанию это `gitsail.yaml` в текущем каталоге.

| Команда | Назначение |
|---|---|
| `gitsail init PATH --branch BRANCH` | Создать начальную конфигурацию хоста и пустую структуру репозитория. |
| `gitsail config check` | Проверить синтаксис и поля конфигурации хоста. |
| `gitsail validate` | Проверить настройки приложений и отрендеренные Compose-файлы. |
| `gitsail plan` | Показать планируемые изменения. |
| `gitsail apply` | Применить изменения и завершить работу. `--wait` повторяет попытки до готовности Compose; `--timeout` задаёт общий таймаут (по умолчанию `15m`). |
| `gitsail run` | Постоянно применять изменения с периодической проверкой источника. |
| `gitsail template export compose --output FILE` | Экспортировать встроенный шаблон Compose для настройки. |
| `gitsail secrets encrypt` / `decrypt` | Зашифровать или расшифровать значения с помощью age. |
| `gitsail install` | Установить systemd-службу в Linux. |

Флаги конкретной команды смотрите в `gitsail <команда> --help`. Рецепты: [установка](../recipes/install.md), [секреты](../recipes/secrets.md), [сервер](../recipes/server.md).
