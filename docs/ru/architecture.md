# Как устроен GitSail

GitSail читает зафиксированные снимки Git, объединяет vars приложения для каждого окружения, обрабатывает шаблоны конфигурации, собирает запрошенные образы и обновляет каждое приложение как Compose-проект. Для `prod` используется `base.yaml`; для остальных окружений — `base.yaml` и `stage.yaml`. Все приложения одной установки по умолчанию подключены к общей сети. Это дополнительный материал; начните с [оглавления задач](../../README.ru.md).
