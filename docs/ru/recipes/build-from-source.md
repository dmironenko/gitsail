# Собрать образ из исходного кода

Добавьте блок `build` и шаблон Dockerfile в каталог приложения:

```yaml
build:
  repository: https://github.com/example/service.git
  tag: v1.2.3
```

Создайте файл `Dockerfile.tmpl`. В нём доступны значения `.Vars.build`, например `{{ .Vars.build.repository }}`. GitSail обработает шаблон и соберёт образ с пустым build context. Клонирование и компиляцию исходников выполняйте внутри Dockerfile. Учётные данные `source.auth` применяются только для GitOps-репозитория и не передаются сборке.

Образ идентифицируется репозиторием, тегом и отрендеренным Dockerfile. Измените один из этих параметров, чтобы запустить новую сборку. Перемещение ветки или тега без изменения его имени сборку не запускает. См. [справочник полей приложения](../reference/app-configuration.md).
