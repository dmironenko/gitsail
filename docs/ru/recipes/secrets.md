# Хранить и использовать секреты

Храните зашифрованные значения в vars приложения в формате `ENC[...]`. Зашифруйте значение с помощью age-ключа хоста:

```sh
printf '%s' 'secret-value' | gitsail secrets encrypt --key-file ./gitsail.agekey
```

Скопируйте результат в YAML. Укажите `age_key_file` в конфигурации хоста и храните закрытый ключ вне Git. GitSail расшифровывает значения до объединения vars и рендеринга шаблонов. В отрендеренном состоянии есть открытый текст, поэтому ограничьте доступ к `state_dir` и держите его вне репозитория. Секреты не попадают в отчёты.

Чтобы расшифровать значение для проверки, используйте `gitsail secrets decrypt --key-file ./gitsail.agekey` и передайте шифротекст через stdin. Не коммитьте расшифрованные данные или закрытый ключ.
