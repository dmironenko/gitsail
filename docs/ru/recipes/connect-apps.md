# Связать два приложения

Приложения одной установки по умолчанию подключены к общей сети. Для обращения к другому приложению используйте имя его Compose-сервиса как hostname. Например, сервис `api` может обращаться к `http://catalog:8080`, если в другом приложении есть сервис `catalog`.

Имена сервисов должны быть уникальными во всех namespace. В окружении `prod` GitSail сохраняет имя сервиса. В остальных окружениях добавляется суффикс `-<окружение>`: `catalog` превращается в `catalog-stage`. GitSail переписывает ссылки Compose-сервисов внутри одного приложения, но URL в настройках приложения нужно формировать с учётом имени окружения.

Приложения обновляются независимо. Клиент, зависящий от другого приложения, должен повторять запросы до готовности сервера. `depends_on` задаёт порядок только для сервисов одного приложения. Явные `networks` или `network_mode` заменяют сетевые значения по умолчанию. См. [окружения stage](stage.md).
