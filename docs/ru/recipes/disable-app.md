# Отключить приложение или окружение

Чтобы отключить приложение вне production, удалите его `vars/stage.yaml`: отсутствие файла отключает приложение во всех не-prod окружениях. Чтобы отключить приложение везде, задайте `compose.x-gitsail.enabled: false` в vars или удалите каталог приложения из репозитория.

GitSail удалит контейнеры приложения, но сохранит тома и образы. Их можно использовать, если включить приложение снова. Удаление окружения из конфигурации также удалит контейнеры окружения, сохранив тома и образы. GitSail не удаляет тома и образы автоматически.
