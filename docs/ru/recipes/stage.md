# Создать stage или персональное окружение

В конфигурации хоста сопоставьте имя окружения с Git-веткой:

```yaml
source:
  branches:
    prod: main
    stage: dev
```

Для `prod` читается только `vars/base.yaml`. Для любого другого окружения GitSail читает `base.yaml`, затем `stage.yaml`. Добавьте `apps/<namespace>/<app>/vars/stage.yaml`, чтобы включить приложение в stage; достаточно пустого файла с `{}`. Если файла нет, приложение отключено во всех не-prod окружениях.

Для персонального окружения добавьте, например, `alice` и сопоставьте его с веткой. Имена сервисов получат суффикс `-alice`. Compose-проекты и тома у каждого окружения отдельные; данные из production не копируются. Удаление окружения из конфигурации удалит его контейнеры, но сохранит тома и образы.

Особое поведение имеет только имя `prod`. Названия веток могут быть любыми. См. [конфигурацию хоста](../reference/host-configuration.md).
